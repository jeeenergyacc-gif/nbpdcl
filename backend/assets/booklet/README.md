# Booklet image assets

Drop optional artwork here. Every file is optional — a missing asset degrades to a
grey caption box so the booklet always generates on a clean checkout.

| Filename | Where it lands |
|---|---|
| `cover.png` | Cover page |
| `power_flow.png` | End of section 1 |

Override this directory with the `BOOKLET_ASSET_DIR` environment variable.

Static screenshots from the manual booklet (SAMAST portal captures, the distribution
map) can be added the same way — they are not derivable from the sheets, so they have to
live here as files.
